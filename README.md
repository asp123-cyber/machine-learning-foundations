# Machine Learning Foundations & Applied Projects

A structured, ground-up repository of intuitive study notes, standalone Python implementations, and an end-to-end housing price prediction pipeline developed during the **Machine Learning Course & Summer Internship** (EngineerCore in association with Effervescence, IIIT Allahabad — June–July 2026).

Every module is written in plain English first—explaining *why* an algorithm works before touching equations or code—followed by clean, runnable Python scripts.

## Curriculum Roadmap

| Module | Topic | Key Concepts Covered |
| :--- | :--- | :--- |
| `01_intro_to_ml` | Foundations of ML | Supervised vs. Unsupervised Learning, Overfitting, Train/Test Splits |
| `02_numpy_and_pandas` | Data Analysis in Python | Vectorization, Indexing, Broadcasting, DataFrames, Cleaning, `groupby` |
| `03_matplotlib_visualization` | Scientific Visualization | Line, Scatter, Histogram, Bar Plots, Subplots, Styling, 600 DPI Exports |
| `04_linear_regression` | Linear Regression | OLS Normal Equation, Gradient Descent, Residuals, MSE, RMSE & $R^2$ |
| `05_supervised_learning_and_knn` | Supervised Learning & KNN | Distance Metrics, Feature Scaling, Choosing $K$, Decision Boundaries |
| `06_comparing_classification_models` | Classification Benchmark | Logistic Regression, KNN, Trees, Random Forest, SVM, Naive Bayes, Confusion Matrix, ROC-AUC |
| `07_kmeans_clustering` | K-Means Clustering | Centroid Iteration, WCSS / Inertia, Elbow Method, Initialization Pitfalls |
| `08_apriori_association_rules` | Apriori Algorithm | Market Basket Analysis, Support, Confidence, Lift, Apriori Pruning |
| `09_project_housing_price_prediction` | **Capstone Project** | End-to-End Housing Price Pipeline (EDA, Leakage-Free Scaling, Model Comparison) |
